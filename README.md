# ⛽ BBM-POS

**BBM-POS** adalah aplikasi **Point of Sale (POS)** sederhana berbasis web untuk mensimulasikan sistem kasir penjualan bahan bakar minyak (BBM).

Dibangun menggunakan **HTML, CSS, dan JavaScript** dengan tampilan sederhana, modern, dan mudah dikembangkan.

---

## ✨ Features

- ⛽ Pilihan jenis BBM
- 💰 Perhitungan harga otomatis
- 🧮 Perhitungan total transaksi
- 💵 Input nominal pembayaran
- 💸 Perhitungan kembalian
- 🧾 Sistem transaksi kasir
- 📋 Riwayat transaksi
- 🔄 Reset transaksi
- 📱 Responsive design
- ⚡ Tanpa database dan backend

---

## 🧮 Transaction Flow

```text
Pilih BBM
    ↓
Masukkan jumlah pembelian
    ↓
Sistem menghitung total
    ↓
Masukkan pembayaran
    ↓
Sistem menghitung kembalian
    ↓
Transaksi selesai
    ↓
Transaksi masuk ke riwayat
```
